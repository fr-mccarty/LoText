**Description** (4000):
LoText is a plain-text editor built around a simple idea: one window is one folder, and one file is open at a time.

There are no tabs, no preview pane, no split view. You open a folder, the files appear in the sidebar, and you write. The text is plain text that any other app can read.

FOLDER BASED
• Each window belongs to one folder. Create, rename, duplicate, move and delete files and folders right in the sidebar.
• Find File (⇧⌘P) jumps to any file in the folder by name.
• Go to Last File (⇧⌘O) switches back to the file you were just in.
• Recent Folders brings back the places you work.

A FOCUSED EDITOR
• Bold and italic (⌘B / ⌘I), duplicate line, cut line, move lines up and down.
• Find and replace, with Use Selection for Find.
• Adjustable font and font size, and dark mode that follows the system.

PRINTING THAT LOOKS FINISHED
• Markdown headings, paragraphs, tables and emphasis print as a properly set page.
• Print presets hold your margins, letterhead, headers, footers and page numbers.
• Letter and A4 paper.

YOUR FILES, AT HOME OR ON A SERVER
• Work with a folder on your Mac, or connect to a folder on a remote server over SSH.
• LoText also shows images, PDFs, zip archives and the text of documents without opening them in the editor.

PICKS UP WHERE YOU LEFT OFF
• Quit with several windows open and they come back with the same file and scroll position.
• Unsaved changes are kept safe if the app closes unexpectedly.

No account, no subscription, no tracking. Just your text.
